# Support

This repository is in a preservation/restoration phase. The original package has not yet been reassembled and verified as a clean installation from this repository.

## Before asking for help

Please check:

- [Project status](docs/PROJECT_STATUS.md)
- [Installation status](docs/INSTALLATION_STATUS.md)
- [Restoration notes](docs/RESTORATION.md)

## When reporting a problem

Include as much of the following as applies:

- GTA III edition and version (the project targets the original PC release).
- CLEO library/version.
- Sanny Builder version and selected edit mode.
- Whether the issue occurs with the untouched original package or a recovered/rebuilt script.
- Exact installation folder layout.
- Steps to reproduce and expected/actual behavior.
- Relevant error message, crash address, or log excerpt.

Do not post personal data, account tokens, or unrelated private files.

## Scope

Please do not use feature requests or support reports as evidence that a feature has been implemented or tested. Functional upgrades are deferred until the original baseline and release process are established.
