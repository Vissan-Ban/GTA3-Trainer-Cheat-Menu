This document records the publicly listed release of this project. It is provenance information, not a claim that the archive has been restored into this Git repository.

## Published description and controls

The release description identifies this as a GTA III cheat menu based on Bilinmeyen Bey, with a visual menu and ten option groups: VEHICLE, TELEPORT, OBJECT, ALLY, WEATHER, MISC, WEAPON, SKIN, TIME, and MISSION.

Published controls:
- Press the tilde key plus a number key (not the numeric keypad) to open.
- Left/right arrow keys to select.
- Enter to confirm.
- Backspace to exit.

Published installation instructions say to place the `cleo` and `models` folders in the GTA III root directory and require `cleo.asi`.

## Attribution recorded in the release

The public description credits Bilinmeyen Bey as the trainer base and Lost_Foever (dim / d88) for the mission-loading component. It also states that Vissan_Ban modified the mission-loading flow and added the time-adjustment and skin-change options.

These credits are transcribed as historical release metadata and should be retained unless the original author explicitly requests a correction.

## Restoration status

The public listing confirms that a downloadable archive was published, but does not by itself verify the contents of any copy currently held in this repository. The original compiled CLEO scripts, FXT files, TXD, documentation, and screenshot must remain a separate, unmodified release archive when added. Decompiled text belongs under `source/disassembled/` and must not be represented as the original source code.

No script has been decompiled, rebuilt, or tested as part of recording this provenance.
