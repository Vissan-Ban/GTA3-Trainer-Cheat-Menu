# Security policy

This project is a legacy single-player game modification. The repository is currently in restoration and does not yet publish a newly verified runtime package.

## Reporting a security concern

Please do not publish exploit details, malicious files, or sensitive personal information in a public issue. Contact the repository owner privately through the contact method listed on their GitHub profile.

Include the affected file or commit, the potential impact, and safe reproduction details where possible.

## Supported versions

There are currently no maintained packaged releases from this restoration repository. The original October 2022 package is treated as historical material, not as a currently supported security release.
